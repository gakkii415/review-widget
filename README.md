# Review widget

公式データから原文が英語の星5レビューを投稿日が新しい順に表示する、埋め込みウィジェットです。全文の一覧でView Moreを押すと3〜5件ずつ追加します。表示フォントはArialです。

## 読めるレビューを優先する表示

ホームには最低3件（対象が3件未満なら全件）を表示します。短いレビューは全文、長いレビューは数文が読める原文の冒頭を表示し、Read full reviewで全文を開けます。AIによる要約や言い換えはしません。フレームの高さによって文章を2行へ縮めたり、最初の3件を削ったりしません。

スマホでは本文をカードの横幅全体で表示し、投稿写真はその下へ置きます。PCでは本文横に180pxの写真を表示します。View Moreは小さな中央配置ボタンを維持します。

Google Sitesの外枠が短い場合、レビューを隠す代わりにフレーム内をスクロール可能にします。これは読み取り不能を防ぐための安全策です。二重スクロールをなくすにはGoogle Sites側の埋め込み枠を3件とView Moreが収まる高さへ広げる必要があります。外部ページからGoogle Sitesの親フレーム高さを自動変更できるとは想定しません。旧来の1140pxという目安を必須の上限にしないでください。必要な高さは本文・画像・表示幅で変わります。

## 保存先と削除

**レビュー本文・顧客名・投稿写真・実データの画面キャプチャをGitへコミットしないでください。** `.gitignore`だけでなく、公開処理の書き込み権限とテストでこの方針を維持します。

毎日03:15 JSTを予定時刻として、GitHub Actionsの一時作業領域で最新データから`dist/index.html`を生成し、GitHub Pagesへ配信物としてデプロイします。GitHubの実行遅延や障害で更新が遅れる場合があります。配信物はGitの変更履歴には入りません。

取得した一覧から毎回全件を作り直します。過去のスナップショットとはマージしません。取得一覧にないレビューや、英語・星5の対象外になったレビューは次の成功した更新で表示対象から外れます。投稿日が古くてもGoogleに現存する対象レビューは、View More用に残します。

デプロイ用の一時アーカイブは公開処理の終了時に削除します。異常終了で削除できなかった場合の保存期間は1日です。レビューを含むスクリーンショットはアップロードしません。既存の配信サイト・利用者やCDNのキャッシュ・外部のコピーまで即時消去を保証するものではありません。

取得元のGASには最大6時間の一時キャッシュがあります。取得できない場合は古いレビューを再利用せず、Googleへ案内するデータなし画面を生成します。ブラウザ上でも取得元データから48時間以上経過したレビュー表示は停止します。ただし、これは配信サービス側の障害時に静的ファイルそのものを削除する仕組みではありません。

## 検索と公開範囲

配信用HTMLに`noindex, nofollow, noimageindex`を設定し、Googleなど対応する検索エンジンによる掲載を抑止します。別途の公開`reviews.json`は生成・配信しません。表示用データ・CSS・JavaScriptをHTMLに含めるので、通常の閲覧時にはGAS・GBPへの通信も追加JSON取得も不要です。

これは非公開化ではありません。URLを開く閲覧者は表示データを取得できます。Google Mapsの元のレビューや、第三者の保存・転載を消すものでもありません。

## 開発・公開

`npm ci`、`npm test`、`npm run build`。`npm run test:browser`は`dist/`と公開URLで検証します。短い600〜700pxのフレームでも本文を削らず3件目とボタンへ到達できること、長文・写真付き・高さ変更を確認します。配信用テンプレートは`templates/index.html`です。`config.json`はビルド時の取得先だけに使用し、配信しません。

公開は`.github/workflows/release.yml`のGitHub Pages artifact方式です。GitHub PagesのSourceにはGitHub Actionsを指定します。旧来のブランチ公開用`index.html`/`widget.js`は新しい配信物には含めません。表示バージョンの正本は`VERSION`で、配信用テンプレートにも同じ`vN`を埋め込みます。埋め込みURLは同じ`?embed=1`のまま使用します。
