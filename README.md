# Review widget

公式データ取得エンドポイントから、原文が英語の星5レビューを選定・表示するウィジェットです。

## 構成と操作

- `index.html`: レビュー専用ページ。View Moreで3〜5件ずつ追加。
- `?embed=1`: ホームページ埋め込み用。高さ1140pxを推奨。本文が長い場合は全文へのリンクを表示。
- `config.json`: 公開データ取得先と`pinnedReviewIds`。固定表示したいレビューIDを優先順で追加できます。
- 上部の評価・件数は全レビューの公式値。カードだけを言語・星で絞り込みます。
- 通常のFeaturedは内容・文字量・新しさ・重複を機械判定します。Newestでは投稿日順に切り替えます。

言語判定が難しい短文は非表示になる場合があります。翻訳を英語の原文として扱いません。レビュー本文・顧客データはリポジトリへ保存しません。公式APIから紐付けて取得できない投稿写真は表示しません。

## 開発と公開

`npm install`、`npm test`、`npm run build`。以後は`npm ci`を使用します。

mainへの変更でテスト・ビルド・実データによるブラウザ検証後にPagesを更新します。表示バージョンは`VERSION`と画面内の`v1`を同じ変更で更新してください。APIキー・OAuth情報をフロントへ入れないでください。

## Google Sitesへの設置

Google Sitesの埋め込みに、公開URL末尾へ`?embed=1`を付けたURLを指定し、高さを1140pxに設定します。埋め込み内では追加表示せず、View Moreから専用ページを開くため、レビュー一覧の二重スクロールを避けられます。Google Sites側の編集・公開は別途必要です。
