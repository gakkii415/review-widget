# Review widget

公式データ取得エンドポイントから、原文が英語の星5レビューを選定・表示するウィジェットです。

## 構成と操作

- `index.html`: レビュー専用ページ。View Moreで3〜5件ずつ追加。
- `?embed=1`: ホームページ埋め込み用。高さ1140pxを推奨。本文が長い場合は全文へのリンクを表示。
- `config.json`: 公開データ取得先と`pinnedReviewIds`。固定表示したいレビューIDを優先順で追加できます。
- 上部の評価・件数は全レビューの公式値。カードだけを言語・星で絞り込みます。
- 表示対象は原文が英語の星5レビューで、常に投稿日が新しい順です。
- 投稿写真は公式の`reviewMediaItems`に明示的に紐付いた写真のみ使用します。ホームは最初の1枚、専用ページは最大4枚を表示します。動画は対象外です。

言語判定が難しい短文は非表示になる場合があります。翻訳を英語の原文として扱いません。レビュー本文・顧客データはリポジトリへ保存しません。写真が取得できないレビューへ別の写真を対応付ける処理はありません。

## 開発と公開

`npm ci`、`npm test`、`npm run build`。

レビュー本文は毎日03:15 JSTにGASから`reviews.json`へ静的スナップショット化し、通常の閲覧ではGAS通信をせず同一オリジンから即時取得します。スナップショット取得に失敗した場合のみGASへフォールバックします。mainへの変更でテスト・ビルド・実データによるブラウザ検証後にPagesを更新します。検証では表示件数、追加読み込み、投稿日順、幅320/390/768pxの埋め込み、写真の表示と写真が多い場合の高さを確認します。表示バージョンは`VERSION`と画面内の`v1`を同じ作業単位で更新してください。APIキー・OAuth情報をフロントへ入れないでください。

## Google Sitesへの設置

Google Sitesの埋め込みに、公開URL末尾へ`?embed=1`を付けたURLを指定し、高さを約1140pxまで広げます。埋め込み内では追加表示せず、View Moreから専用ページを開くため、レビュー一覧の二重スクロールを避けられます。Google Sites側の編集・公開は別途必要です。
